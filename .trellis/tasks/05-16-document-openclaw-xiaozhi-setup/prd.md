# Document OpenClaw Xiaozhi Setup

## Problem

The GitHub default branch still lacks a practical install and usage guide for the OpenClaw Xiaozhi bridge. The stable lifecycle fixes also live on a feature branch instead of `main`.

## Goals

- Add GitHub-facing setup, run, stop, validation, and usage instructions.
- Explain the relationship between Xiaozhi and OpenClaw.
- Include concrete voice prompts that route work to OpenClaw.
- Merge the stable branch into `main` and push it to GitHub.

## Acceptance Criteria

- `README.md` contains a clear OpenClaw Xiaozhi quick start.
- The docs mention single-instance behavior and low-power hidden startup.
- `main` contains the stable lifecycle fixes and documentation.
